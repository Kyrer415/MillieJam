# GameForMillieJam

Короткая логическая игра от первого лица, разработанная в рамках MillieJam за 7 дней.

## 🎮 Геймплей
Игроку необходимо решить 4 пространственные загадки, чтобы открыть секционные двери и накормить кота. 
* **Логика прогресса:** Игра разделена на 2 секции. Решение загадок открывает доступ к следующей зоне.
* **ИИ Кота:** Кот перемещается по заранее заданным точкам. При открытии новой секции он динамически телепортируется в случайную точку новой зоны.

## 🛠 Стек технологий
* **Движок:** Unreal Engine 5.7.4
* **Язык:** Blueprints / C++ 

## 📦 Как запустить проект
1. Склонируйте репозиторий.
2. Кликните правой кнопкой мыши по файлу `[Название].uproject` и выберите **Generate Visual Studio project files** (если есть C++).
3. Откройте проект в Unreal Engine и запустите сцену в папке `Content/Maps`.
